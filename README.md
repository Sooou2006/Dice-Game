# Play Dice 🎲

A simple Flutter dice game with a dark theme.

## How it works
- Press **roll** to roll two dice.
- If the total is **10 or more**, the happy image and **You Win** appear.
- Otherwise, the sad image and **You Lose** appear.
- Press **reset** to return both dice to 1, the total to 2, and the sad image.

## Run the app
1. Install Flutter and set up an emulator or connect a device.
2. Open a terminal in this project folder.
3. Run:
   ```bash
   flutter pub get
   flutter run
   ```
